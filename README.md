# 朝堂 ChaoTang

> 百官进言，圣裁由你。

朝堂是一款本地运行的多角色 AI 议事工具。提出一个难题，让不同立场的角色依次分析、并行回答，或由“丞相”拆解任务后分派给其他角色。每位角色可以绑定不同的模型，最后由你决定如何取舍。

例如：**“我有四周时间和 5000 元预算，应该先做桌面工具还是内容产品？”** 户部尚书分析成本，御史指出风险，大将军提出执行路径，丞相汇总意见。多角色意见可帮助发现盲点，但不保证结论正确；重要决策请核对事实和数据。

## 当前可用的功能

- 六位预设角色，支持更换主题与角色提示词。
- 串行、并行和 Agent 三种朝议节奏；可指定参与角色。
- 配置各角色使用的模型，连接 OpenAI 兼容接口或本地 Ollama。
- 保存本地朝议历史；桌面版可在你选定的工作目录内读取文件、搜索代码和使用工具。

> 模型服务可能收费。朝堂不附赠模型额度；请求会发往你配置的模型服务。部分厂商接口与 OpenAI 格式有差异，请先在设置页测试连接。

## 快速开始

需要 Node.js 22.12 或更新版本与 npm。克隆仓库后，在项目根目录运行：

```bash
npm ci
npm run electron:dev
```

打开设置页，添加一个可用的模型 API Key，或配置本地 Ollama。回到首页，输入议题，选择参与角色后开始朝议。

只体验网页界面可运行 `npm run dev`，访问 `http://localhost:3000`。网页模式没有 Electron 的本地文件与命令能力。

构建桌面安装包：

```bash
npm run electron:build
```

安装包输出到 `release/`，该目录不随源码提交。公开分发前请重新构建并亲测安装流程。

## 发布与安全说明

- 桌面版的 API Key 使用 Electron `safeStorage` 加密后保存在应用数据目录；旧版存在浏览器本地存储的密钥会在启动时迁移。若系统安全存储不可用，应用会提示错误，不会将新密钥明文保存。
- 网页开发模式的 API Key 仍在浏览器 `localStorage` 中。请勿在公共设备或不受信任的网页部署中输入密钥。
- 桌面文件工具仅可访问你通过系统对话框选定的工作目录；写入文件和创建目录须逐项批准。命令和测试每次执行前都会显示完整命令，请审阅后决定是否批准。**获批准的命令仍可能访问工作目录以外的文件。**
- 模型输出按受限 Markdown 渲染，原始 HTML、图片及危险链接不会直接进入界面。
- 项目尚无自动化端到端测试、代码签名或自动更新。首次公开发安装包前，请在干净的系统上验证安装、密钥迁移及各模型连接。

更详细的限制与漏洞反馈方式见 [SECURITY.md](./SECURITY.md)。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `src/components/ChatSession.vue` | 会话与朝议交互 |
| `src/services/agent/` | Agent 编排与上下文处理 |
| `src/services/llm/` | 模型请求与流式响应 |
| `src/services/tools/` | 工具定义与处理器 |
| `electron/` | 桌面主进程、文件与命令权限边界 |
| `docs/` | 设计、使用与开发记录；部分旧记录描述的是历史状态 |

技术栈：Vue 3、TypeScript、Vite、Pinia、Element Plus、Electron。
