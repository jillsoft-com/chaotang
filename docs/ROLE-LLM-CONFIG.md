# 🎭 角色 LLM 配置功能说明

## ✨ 功能概述

现在你可以为每位朝臣单独指定使用的 LLM 模型，让不同的角色使用最适合的 AI 模型！

## 🎯 使用方法

### 1. 访问设置页面
- 点击首页侧边栏的"设置"按钮
- 或在地址栏访问 `/settings`

### 2. 切换到角色配置
在设置页面顶部，点击"角色配置"标签

### 3. 配置每个角色
对每位朝臣，你可以选择：
- **提供商**：OpenAI / Claude / DeepSeek / Ollama（本地）
- **模型**：从下拉列表中选择具体模型

### 4. 保存配置
- 每个角色可以单独保存
- 配置将保存在本地浏览器中
- 下次启动时自动加载

## 🎨 推荐配置方案

### 方案一：性价比优先
```
所有角色 → OpenAI gpt-4o-mini
优点：成本低，速度快
适用：日常讨论，快速迭代
```

### 方案二：质量优先
```
丞相、太傅 → OpenAI gpt-4o 或 Claude 3.5 Sonnet
其他角色 → OpenAI gpt-4o-mini
优点：核心角色质量最高
适用：重要决策，深度分析
```

### 方案三：本地优先（隐私）
```
所有角色 → Ollama + qwen2.5 系列
优点：完全本地，数据隐私
适用：敏感话题，无网络环境
```

### 方案四：多样化（默认方案）
```
不同角色使用不同提供商
优点：集各家之长
- OpenAI：均衡性能
- Claude：逻辑严谨
- DeepSeek：数据处理
- Ollama：快速响应
```

## ⚙️ 高级操作

### 批量修改
目前需要逐个保存每个角色的配置。

### 重置为默认
点击"恢复默认"按钮，所有角色将恢复为初始配置。

### 查看当前配置
在角色配置卡片中可以看到每个角色当前使用的模型。

### 配置持久化
- 配置保存在 `localStorage`
- 清除浏览器缓存会丢失配置
- 建议记录重要配置

## 🔒 隐私说明

- ✅ 所有配置保存在本地浏览器
- ✅ 不会上传到服务器
- ✅ 仅在你的设备上生效
- ⚠️ 清除浏览器数据会丢失配置

## 🐛 常见问题

### Q1: 选择模型后没有效果？
A: 需要点击"保存"按钮，配置才会生效

### Q2: Ollama 模型无法使用？
A: 确保已启动 Ollama 服务，并下载了对应模型
```bash
# 下载模型示例
ollama pull qwen2.5:7b
```

### Q3: 如何知道模型是否可用？
A: 需要先在"API 密钥"标签页配置对应的 API Key

### Q4: 可以为同一个模型配置多个角色吗？
A: 可以！多个角色可以使用相同的模型

### Q5: 配置丢失了怎么办？
A: 配置保存在 localStorage，清除浏览器数据会丢失。建议截图保存重要配置。
