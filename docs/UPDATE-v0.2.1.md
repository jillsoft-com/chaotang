# 🔄 更新说明 - v0.2.1

**更新时间**: 2026-10-08  
**版本**: v0.2.1

## 📋 更新内容

### ✨ 界面优化

#### 删除 API 密钥标签页
- ❌ 移除了旧版的"API 密钥"标签页
- ✅ 简化为两个标签页：
  1. **LLM 管理** - 统一的 LLM 配置管理
  2. **角色配置** - 为角色选择 LLM

#### 原因
- 新版 LLM 管理系统已完全替代旧版 API Key 配置
- 所有功能都可以在"LLM 管理"中完成
- 避免功能重复和界面混乱
- 提供更清晰的用户体验

## 🎯 迁移指南

### 如果你之前使用旧版 API Key

#### 旧版方式（已废弃）
```
设置 → API 密钥
- OpenAI API Key
- Claude API Key  
- DeepSeek API Key
- Ollama 服务地址
```

#### 新版方式（推荐）
```
设置 → LLM 管理
1. 点击"添加 LLM"
2. 填写配置：
   - 名称：我的 OpenAI
   - 提供商：OpenAI
   - 模型：gpt-4o-mini
   - API Key：sk-...
3. 测试连接
4. 保存配置
```

### 迁移步骤

1. **添加 LLM 配置**
   - 进入"LLM 管理"标签
   - 点击"添加 LLM"
   - 填写 API Key 和配置
   - 测试连接确保可用
   - 保存配置

2. **更新角色配置**
   - 切换到"角色配置"标签
   - 为每个角色选择新添加的 LLM
   - 点击保存

3. **验证功能**
   - 返回首页
   - 创建新议题
   - 测试辩论功能
   - 确认 LLM 正常工作
