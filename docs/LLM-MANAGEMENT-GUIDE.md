# 🎯 LLM 管理系统 - 使用指南

## ✨ 功能概述

全新的 LLM 管理系统让你可以：
- ✅ 添加多个 LLM 配置
- ✅ 测试 LLM 连接是否可用
- ✅ 为每个角色选择已添加的 LLM
- ✅ 设置默认 LLM
- ✅ 编辑和删除配置

## 🚀 快速开始

### 1. 访问设置页面
- 点击首页侧边栏的"设置"按钮
- 或在地址栏访问 `/settings`

### 2. 添加 LLM 配置

#### 步骤：
1. 点击"LLM 管理"标签
2. 点击"添加 LLM"按钮
3. 填写配置表单：
   - **名称**：给这个配置起个名字（如："我的 GPT-4"）
   - **提供商**：选择 OpenAI/Claude/DeepSeek/Ollama
   - **模型**：从下拉列表选择模型
   - **API Key**：输入对应的 API 密钥
   - **自定义 API 地址**（可选）：如果使用代理或自定义端点
   - **温度**：0-2 之间的数值（控制随机性）
   - **最大 Token**：单次生成的最大 token 数
4. 点击"测试连接"验证配置是否正确
5. 点击"保存"完成添加

### 3. 测试 LLM 连接

在添加或编辑 LLM 时：
1. 填写完配置信息
2. 点击"测试连接"按钮
3. 等待测试结果：
   - ✅ **成功**：显示连接延迟和模型信息
   - ❌ **失败**：显示错误原因

**测试会验证**：
- API Key 是否有效
- 网络连接是否正常
- 模型是否可用
- API 地址是否正确

### 4. 为角色选择 LLM

切换到"角色配置"标签：

1. 查看 6 位朝臣列表
2. 为每个角色从下拉菜单选择已添加的 LLM
3. 点击"保存"按钮

**提示**：
- 只能选择已添加的 LLM
- 建议先添加并测试 LLM，再分配给角色
- 可以多个角色使用同一个 LLM

### 5. 管理 LLM 配置

#### 设为默认
- 点击"设为默认"按钮
- 新添加的角色将使用默认 LLM
- 只有一个 LLM 可以是默认的

#### 编辑配置
- 点击"编辑"按钮
- 修改配置信息
- 点击"保存"

#### 删除配置
- 点击"删除"按钮
- 确认删除操作
- ⚠️ **注意**：删除后，使用该 LLM 的角色将无法正常工作

## 🔧 配置参数说明

### 温度 (Temperature)
- **范围**：0 - 2
- **作用**：控制回复的随机性
- **建议值**：
  - 0.0 - 0.3：确定性回答（数据分析）
  - 0.5 - 0.8：平衡（一般对话）
  - 1.0 - 1.5：创意性回答（头脑风暴）
  - 1.5 - 2.0：高度随机（诗歌创作）

### 最大 Token (Max Tokens)
- **作用**：限制单次生成的长度
- **建议值**：
  - 100 - 500：简短回复
  - 1000 - 2000：一般讨论
  - 4000+：详细分析

### 自定义 API 地址
使用场景：
- API 代理
- 自建模型服务
- 企业私有部署
- 开发测试环境

**示例**：
```
OpenAI 代理：https://your-proxy.com/v1
本地服务：http://localhost:8080/v1
```

## ⚠️ 常见问题

### Q1: 测试连接失败怎么办？
**检查**：
1. API Key 是否正确
2. 网络连接是否正常
3. API 地址是否正确
4. 是否需要代理

**解决**：
- 重新输入 API Key
- 检查网络
- 使用正确的 API 地址
- 如果使用代理，填写自定义 URL

### Q2: 删除 LLM 后角色怎么办？
角色将无法正常工作。建议：
1. 先为角色选择其他 LLM
2. 再删除旧的 LLM 配置

### Q3: 如何备份配置？
配置保存在浏览器 localStorage：
- 清除浏览器数据会丢失
- 建议截图保存重要配置
- 或使用浏览器数据导出工具

### Q4: 多个角色可以使用同一个 LLM 吗？
**可以！** 这是推荐的做法，特别是使用成本较高的模型时。

### Q5: 可以添加多个同提供商的 LLM 吗？
**可以！** 例如：
- 添加两个 OpenAI：
  - "GPT-4o（高质量）"
  - "GPT-4o Mini（快速）"
- 根据角色需求选择

### Q6: Ollama 模型如何使用？
1. 确保 Ollama 服务已启动
2. 下载对应模型：
   ```bash
   ollama pull qwen2.5:7b
   ```
3. 在"自定义 API 地址"填写：
   ```
   http://localhost:11434/v1
   ```
4. 不需要 API Key

4. 更新角色配置
