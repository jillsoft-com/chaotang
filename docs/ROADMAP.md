# 朝堂产品迭代路线图 (Roadmap)

## v0.3 — 体验优化（进行中）

### ✅ 已完成
- 会话内搜索：🔍 按钮 + 展开搜索条，Ctrl+F 快捷键，实时高亮跳转
- 历史搜索入口：左侧工具栏搜索按钮，自动聚焦历史搜索框
- 消息操作菜单：悬浮发言显示复制📋 / 重试🔄按钮
- 轮次索引导航：左侧浮动横线索引，以圣上发言为准，悬浮预览前 10 字
- 字体大小调节：设置页通用设置中滑动条调节，重置按钮，持久化到 localStorage
- 角色自定义头像：点击角色头像弹出 Emoji 面板 / 图片 URL 输入，持久化到 localStorage
- 工具栏精简：圆形图标按钮 + tooltip，响应式布局
- 角色管理：Popover 选人，控制参与讨论的角色
- 附件功能：文件选择、拖拽、内容注入提示词
- 工作目录：显示文件夹名称，支持项目级上下文
- 图片附件：Ctrl+V 粘贴截图，缩略图预览，多模态模型可分析
- 会话导出 Markdown：📥 导出按钮 + Ctrl+E，含圣旨、决策报告、Token 统计
- 快捷键体系：Ctrl+N 新建 / Ctrl+H 历史 / Ctrl+, 设置 / Ctrl+Shift+F 搜索 / Ctrl+F 会话搜索 / Ctrl+E 导出
- 跨会话全文搜索：活动会话 + 历史朝议合并检索，按时间降序
