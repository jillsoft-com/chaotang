# 朝堂 ChaoTang｜产品介绍与宣传文案

> 从一道旨意，到一份可审阅的交付。

## 一句话介绍

**朝堂是一款本地优先的桌面 AI 协作应用。** 您提出目标，丞相组织计划，多位 AI 角色分工讨论与执行；任务推进、文件变更和验收结果，都在会话中呈现，最后由您拍板。

## 对外介绍

复杂工作需要有人出主意，也需要有人把事情办成。朝堂把这两件事放进同一张桌子：六位各有所长的 AI 大臣可以围绕议题展开朝议，也可以由丞相将目标拆成任务，交给合适的角色执行。

写代码时，朝堂可以先展示计划，供您调整子任务、执行者和执行模式；随后按任务树处理依赖，让适合并行的只读任务协同推进。执行过程中，它能够调用文件、命令与测试工具，记录进度和异常，并在交付前展示文件差异与验收结果。您看到的既是回答，也是工作如何完成的过程。

朝堂适合需要多角度判断、持续推进和审阅结果的工作：从方案论证、资料整理，到跨文件编码任务。它运行在桌面端，会话和设置以本机存储为主；您可配置所使用的模型服务，并决定何时批准计划、命令与文件操作。

## 核心体验

### 一殿共议：让不同立场充分发言

丞相统筹，六位大臣从各自视角分析同一问题。您可以选择参与角色、点名发言、继续追问，也可以在讨论后拍板，形成结构化决策报告。遇到需要执行的目标，朝议可以进入 Agent 模式，由讨论走向行动。

### 先看计划，再令其执行

丞相拆解目标后，计划审阅面板会列出子任务。您可以增删一级任务、修改描述和执行者，并选择自主执行或只读模式。确认之后，任务树按依赖推进；节点状态、预算和执行事件为长任务提供可追踪的脉络。

### 把编码过程带到桌面

选定工作目录后，朝堂可以读取项目结构、检索代码和符号，调用文件与命令工具完成修改。自主执行路径包含测试、Lint 与验收环节；发现问题时，可依据工具反馈继续修复。最终交付面板集中展示文件差异、检查结果和待关注事项，便于您决定是否采纳。

### 让关键操作留有把关点

写入文件和执行命令需要审批。交付撤销会核对文件版本，遇到后续修改或缺少可靠原始内容时提示冲突。任务树保存快照，支持在中断后核对状态并尝试恢复。朝堂将执行权交给 Agent，同时把关键决定留给您。

## 适合谁

- **独立开发者**：需要一个能规划、查代码、修改、验证并交付的桌面助手。
- **技术负责人**：希望先比较方案，再让任务分工推进，并检查变更与验收依据。
- **产品与研究人员**：希望多角色讨论需求、风险和取舍，形成可回看的决策记录。
- **小团队**：希望把复杂目标拆成可追踪的任务，减少讨论与执行之间的信息断层。
