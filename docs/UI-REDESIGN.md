## 🎮 使用流程

### 1. 启动应用
```bash
npm run dev
# 访问 http://localhost:3000
```

### 2. 新建朝议
- 点击"新的朝议"按钮
- 或在输入框直接输入议题

### 3. 输入议题
- 在输入框输入议题
- 按 Enter 发送
- 自动开始辩论

### 4. 观看辩论
- 实时查看进度
- 观看大臣发言动画
- 查看发言内容

### 5. 颁布圣旨
- 辩论完成后显示按钮
- 点击"颁布圣旨"
- 输入最终决定

### 6. 查看历史
- 侧边栏点击历史记录
- 或在历史页面浏览

## 🎨 自定义选项

### 修改主题色
编辑 `src/assets/main.css`：
```css
:root {
  --imperial-gold: #d4af37; /* 修改为你喜欢的颜色 */
}
```

### 调整侧边栏宽度
编辑 `src/views/HomeView.vue`：
```css
.sidebar {
  width: 260px; /* 修改为你想要的宽度 */
}
```

### 修改卡片样式
在各个组件的 `<style scoped>` 中调整
